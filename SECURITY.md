# Security and privacy

This is a public historical-source repository. Do not commit credentials, environment files, personal profiles, private email addresses, uploaded documents, live database exports, object-storage exports, audit histories or signed URLs.

The v1.5.1 folder is a sanitised source snapshot. It does not contain the live private platform database, identities, uploads, recommendation history or credentials.

If you discover information that should not be public, contact the repository owner privately rather than opening a public issue containing the data.
