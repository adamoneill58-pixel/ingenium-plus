# INGENIUM+ v1.5 progress

Last updated: 13 September 2026

The authoritative specification is `../V1.5_SPEC.md`. It was supplied at the repository root rather than `docs/V1.5_SPEC.md`; it remains unchanged.

## Existing architecture

- Next-compatible App Router application compiled by vinext/Vite for a Cloudflare Worker.
- React 19, TypeScript, Cytoscape and project-wide CSS in `app/globals.css`.
- Static v1.4 evidence dataset in `lib/data.ts`: 85 entities, 343 relationships, 29 sources and six journeys.
- Eleven routes with shared header/footer; focused directory pages reuse `DirectoryPage` and `EntityCard`.
- `GraphExplorer` owns URL state, modes, filters, Cytoscape, the accessible list, evidence drawer, saved records, comparison and calendar export.
- Browser storage owns saved records, journey steps and private notes. No production account, messaging or enrolment backend exists.
- Sites linkage is in `.openai/hosting.json`. Local changes require a validated saved version and separate deployment.

## Technical risks

- The existing Europe SVG is a finite Cytoscape node; unconstrained panning can reveal its edge.
- The current data model stores declared status text even when dates make that status stale.
- Official pages can disagree internally. Conflicting dates must stay visible as verification required.
- A larger graph needs progressive labels, stable selectors and careful Cytoscape updates to avoid expensive full rebuilds.
- Sample profiles and Chats must never appear to be real people, official enrolment or sent messages.
- Local profile, semester and planner keys need safe parsing and must remain device-only.
- Dynamic App Router records and a Worker build must remain compatible with vinext.

## Current source decisions

- Exact dates and explicit deadline prose outrank stale “Registration Open” or “OPEN” page badges.
- The verified Climate Adapted Urban Infrastructure opportunity is marked `Verification required` because current official sources conflict on its start and enrolment dates.
- The Annual Education Call is marked `Verification required` because the official page contains conflicting deadline summaries.
- CLARITY-AI and SeismicX are marked `Verification required` because their current official schedule details conflict.
- The Innovative Strategies for Wellbeing doctorate is preserved as a verified programme with a closed 21 August 2026 call.
- Learning recognition is advisory: every compatibility route tells students to confirm recognition with their home university.
- Sample profiles, participation and Chats are visually and structurally classified as sample information.

## Specification deviations

- `V1.5_SPEC.md` remains at the repository root because moving or editing the user-supplied authoritative specification was not requested.
- No real student data, message sending, enrolment or authentication backend will be introduced. v1.5 uses browser-local state and labelled sample content as specified.
- Current official imagery will be linked only where provenance and suitability are clear; records without a suitable verified image use the existing graph-first visual system.
