  and running owner bootstrapping queries on unauthenticated visitors.

Optimized:
- Worker entry `dist/server/index.js`: 1,195.5 KB raw (257.2 KB gzip) [-49.3%]

  only when D1 database is unseeded on cold start.
- Worker only runs session setup for `/student` and `/staff*` routes.
- `last_seen_at` updates throttled to a 15-minute window unless email or name changes.
- `bootstrapPrivateOwner` returns early once active administrator membership exists.
