# INGENIUM+ v1.5 — archive notes

v1.5 re-centres the product on a large graph workspace, adds unified Explore and Learning experiences, rich record pages, a browser-local semester builder, optional My Campus profile, deterministic explained recommendations, fictional students and read-only sample chats. Date-derived status logic prevents elapsed deadlines remaining actionable from stale labels. Verified, calculated and sample classifications are exposed throughout.

The archive comes from commit `211482eac37136a627f94643d3d1947c2c121068`, the source of public Sites version 4. The public URL retains the historical `v14` slug. Data validation, five logic tests, TypeScript, production build and 15 rendered routes pass. One React Compiler lint error in `LearningWorkspace.tsx` is a documented historical acceptance gap and was not silently fixed during archiving.
